# Workshop Voluntold Tool Architecture

Based on Chance Arcade - a static React application built by Vite. No server data, accounts, database, telemetry, or runtime network dependency.

## Overview

The Workshop Voluntold Tool is a browser-based random selector featuring:
- **Decision Wheel**: Spin to randomly select from your roster
- **Marble Pursuit**: Physics-based racing game for participant selection
- **Customizable Rosters**: Add names, portraits, and manage participants
- **Level Editor**: Create custom marble race courses

Everything runs locally on your computer. After the first dependency install, no internet access is required.
